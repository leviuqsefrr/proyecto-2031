- La caché offline guarda la aplicación, NO sustituye respaldos de datos.

INSTALACIÓN EN IPHONE CON GITHUB PAGES:
1. Desde tu cuenta de GitHub crea un repositorio nuevo (por ejemplo proyecto-2031). IMPORTANTE: para la prueba solo contiene código, no datos de clientes.
2. Sube los archivos y la carpeta icons/ respetando rutas; asegúrate de subir index.html a la raíz.
3. Abre Settings > Pages > Build and deployment > Deploy from a branch, selecciona main y /(root), y guarda.
4. Abre la dirección HTTPS que GitHub Pages muestra en Safari del iPhone.
5. Safari: Compartir > Añadir a pantalla de inicio > Añadir.
6. Abre la app una vez con internet; luego puedes usar la interfaz offline.
7. Guarda periódicamente un respaldo desde Ajustes > Descargar respaldo; conserva el JSON en Archivos/iCloud.

PRIVACIDAD: GitHub Pages publica el CÓDIGO en internet. Los registros se guardan solo en el navegador/dispositivo local y NO se suben a GitHub. No pegues información real de clientes en archivos del repositorio. Si borras datos del sitio Safari o cambias de dispositivo, necesitarás importar un respaldo. No hay cifrado de datos en almacenamiento local.

No modificar ni sobrescribir C:\Users\xpect\Documents\fg-cotizaciones ni Zora.
